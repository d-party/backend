1"""Pydantic models describing the WebSocket message protocol. 

2 

3These models define the exact shape of every message the streamer consumer 

4emits. The wire format is part of the public contract shared with the Chrome 

5extension and the front-end, so field names, ``action`` values and nesting must 

6not change. 

7 

8Note: ``SerializeAsAny`` is required on the ``response`` field so that, under 

9pydantic v2, subclass-specific fields are kept when serializing a field typed 

10as the ``ResponseBaseFormat`` base class (this matched pydantic v1's default 

11``.dict()`` behaviour). 

12""" 

13

19class User(BaseModel): 

20 """A participant. 

21 

22 Attributes: 

23 user_id: UUID identifying the user. 

24 user_name: display name chosen by the user. 

25 user_icon: react-icons (Font Awesome 6) key string chosen by the user. 

26 Defaults to ``FaRegUser`` so older clients/data that omit it fall back 

27 to the plain user icon. 

28 is_host: whether this participant is the room host (owner). 

29 """

64class Option(BaseModel): 

65 time: float 

66 src: str | None 

67 paused: str 

68 rate: str 

69 part_id: str 

70 

71 @field_validator("paused", "rate", mode="before") 

72 @classmethod 

73 def _coerce_to_str(cls, value): 

74 # The extension sends `paused` as a bool and `rate` as a number; pydantic 

75 # v1 stringified these (e.g. False -> "False"), and the client relies on 

76 # that exact form (`option["paused"] === "False"`). Preserve it under v2. 

77 if value is None or isinstance(value, str): 

78 return value 

79 return str(value)
